# Icônes de l'interface (`src/assets/`)

Fichiers PNG 512×512 (noir sur fond transparent) utilisés par l'onglet « Implantation » :

| Fichier | Usage |
|---|---|
| `selection.png` | outil Sélection |
| `firewall.png` | outil Mur |
| `opened-door-aperture.png` | outil Porte |
| `window.png` | outil Fenêtre |
| `text.png` | outil Texte |
| `flip.png` | boutons Miroir horizontal / vertical |
